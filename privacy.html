Privacy and data use

Effective 13 November 2026

Perry Chat Archive is a personal macOS archive and restore utility maintained by Perry Nelson.

Data used

The utility uploads selected older archived chat files from the owner's Mac to the owner's Google Drive. File names, original paths, sizes, timestamps and checksums are recorded to verify uploads and support restoration.

Google access

The utility requests the Google Drive file permission, which limits access to files created by or explicitly used with the app. The background service checks that the authorized Google account matches the owner's configured account. Access tokens and refresh credentials are stored locally with owner-only file permissions.

Use and sharing

Google user data is used only to provide the personal archive, verification and restore functions. This utility does not sell chat data, use it for advertising, or use it to train AI models. Archive files and restore records are stored in the owner's private Google Drive folders. The utility does not publish or deliberately share those files with other users.

Retention and control

A local file is released only after its cloud copy and restore record pass verification. Cloud archives remain until the owner removes them. The owner can restore files, delete cloud files using Google Drive, or revoke this app's access through their Google Account connections settings.

This website

These informational pages contain no chat content or archive catalog. They include no forms or embedded analytics. The hosting provider may process ordinary website access logs.

Contact

Contact the owner using the support email shown on the Google authorization screen.
